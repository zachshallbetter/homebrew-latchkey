# Latchkey for Homebrew

```bash
brew tap zachshallbetter/latchkey
brew trust zachshallbetter/latchkey
brew install --cask latchkey
```

Installs the notarized Latchkey app and its command-line tool (`latchkey`, and `lk` for short). Homebrew asks you to
trust a tap before installing from it. See https://latchkey.snackstud.io/.
