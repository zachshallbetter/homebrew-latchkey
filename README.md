# Latchkey for Homebrew

```bash
brew tap zachshallbetter/latchkey
brew trust zachshallbetter/latchkey
```

Then either:

- `brew install --cask latchkey`: the notarized Latchkey app with its command-line tool (`latchkey`, and `lk` for short).
- `brew install latchkey-cli`: the command-line tool on its own, for the Mac App Store version of Latchkey.

Homebrew asks you to trust a tap before installing from it. See https://latchkey.snackstud.io/.
